# DSA practice log

A study log, not code — one file per pattern from the plan's Week 1–2 DSA foundations
(`../../faang_python_full_prep.html#w12`). Each pattern file has: the plain-English idea, the
problem list from the plan (as checkboxes), and a running notes section for what actually tripped you
up — the plan's own review step ("write the pattern in plain English... what would you do differently")
is what this is for.

Separate from `docs/tasks/` (project build tasks) and `docs/features/` (project feature docs) on
purpose — this tracks a learning activity, not the trade-pipeline codebase itself.

## How to use each file

1. Attempt the problem without hints for 20 minutes (per the plan's own rule).
2. Check the solution after, read the top community solution.
3. Fill in that problem's row: date, whether you needed hints, and the one-line "what would you do
   differently" note — that reflection is the actual point, not just checking a box.
